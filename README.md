# GST Invoice Maker – Releases

Windows ke liye GST Invoice / Proforma Invoice / Quotation software.

Ye repository sirf software ke **installer aur updates** rakhne ke liye hai. Koi bhi bill ya customer data yahan nahin aata — saara data aapke computer (ya office network folder) par hi rehta hai.

- Install karne ke liye: **Releases** me sabse naya `GST-Invoice-Maker-Setup-x.y.z.exe` download karein.
- Software me **Update → "Internet se naya version check karein"** dabane par yahin se naya version aata hai.
